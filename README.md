# Ai-classification
Определение типа самолета по фото с помощью локальных мультимодальных моделей. 
Сравниваются две модели: `llava` и `minicpm-v4.5`.

## Технологии
- Ollama (локальный запуск моделей)
- Python: `ollama`, `pandas`, `scikit-learn`

## Выборка
30 фото: 15 военных и 15 гражданских. 
Включены сложные случаи (военно-транспортные самолеты, самолеты устаревших типов).
Разметка в именах файлов: `_x` — военный (M), `_y` — гражданский (C).

## Как запустить
1. Установить [Ollama](https://ollama.com/download).
2. Скачать модели:
   ```bash
   ollama pull llava
   ollama pull minicpm-v4.5

Открыть aircraft_classification.ipynb и последовательно выполнить ячейки.
